# Личный сайт Виктора

Сайт: https://rock478.github.io/

Статический сайт без зависимостей и этапа сборки. GitHub Pages публикует корень ветки `main`.

## Редактирование

- `index.html` — тексты, разделы и ссылки.
- `styles.css` — оформление и адаптация для телефона.
- `favicon.svg` — иконка вкладки.
- `assets/images/` — два портрета, созданных встроенным ImageGen на основе фотографии Виктора.
- `assets/documents/` — изображения дипломов и сертификата из `ROCK478/MyAchievements`; показаны на странице целиком, без ссылок на документы.

## Содержание

Факты об окончании школы с золотой медалью и красным аттестатом, учёбе на отлично на третьем курсе УУНиТ, двух победах в «Альфа-Будущее. Стипендии», сумме гранта и названии VR-проекта предоставлены Виктором.

По документам проверены: победа в номинации ООО «АйВиСистемз» на «Кибер-102» (2025), диплом I степени Unlocking Foundations Hackathon (год на дипломе не указан), первое место GameJam@Ufa (2024), третье место «Авиатрон» (2026). Командные награды подписаны как командные. Для стипендии в репозитории найден сертификат 2025 года. Диплом «Студенческого стартапа» — за 2026 год.

На сайте нет формулировок о доказанной медицинской эффективности VR-проекта. Сгенерированные портреты подписаны как AI; это иллюстрации, а не фото с мероприятий.

## Локальный просмотр

В папке проекта выполнить:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8000/ . Остановить сервер: Ctrl+C.

## Публикация изменений

```sh
git add index.html styles.css favicon.svg
git commit -m "Update personal site"
git push origin main
```
