# Личный сайт Виктора

Сайт: https://rock478.github.io/

Статический сайт без зависимостей и этапа сборки. GitHub Pages публикует корень ветки `main`.

## Редактирование

- `index.html` — тексты, разделы и ссылки.
- `styles.css` — оформление и адаптация для телефона.
- `carousel.js` — листание колёсиком, свайпом, стрелками и клавиатурой; увеличение документов внутри страницы.
- `achievements.json` — каталог 24 документов и порядок их показа.
- `favicon.svg` — иконка вкладки.
- `assets/images/` — два портрета, созданных встроенным ImageGen на основе фотографии Виктора.
- `assets/documents/` — изображения всех 24 документов из `ROCK478/MyAchievements`. Каждый показан целиком в одной общей карусели; нажатие открывает увеличение на этой же странице.

## Содержание

Факты об окончании школы с золотой медалью и красным аттестатом, учёбе на отлично на третьем курсе УУНиТ, двух победах в «Альфа-Будущее. Стипендии», сумме гранта и названии VR-проекта предоставлены Виктором.

Сначала показаны грант и стипендия, затем первое место «Открой#Моспром» (2026), победы в хакатонах и призовые места. Далее — проектный опыт, олимпиады, сертификаты участия и обучения. Участие не обозначено как победа, командные награды подписаны как командные. Для стипендии найден сертификат 2025 года; две победы указаны со слов Виктора. Диплом «Студенческого стартапа» — за 2026 год.

Восемь новых PDF-сканов размещены в `scans/` репозитория достижений. Шесть заменили фотографии тех же документов, два добавили новые сертификаты. Веб-превью созданы из этих PDF; сканы сертификата «Альфа-Будущее» и наставничества повёрнуты для чтения. При отсутствии нового скана сохранён прежний оригинал.

Карусель не переключается автоматически. На краях обычная прокрутка страницы продолжается; внутри неё колёсико меняет документ. Поддерживаются клавиши со стрелками, Home/End, ползунок и уменьшение анимации. В режиме увеличения доступны масштаб и закрытие по Escape.

На сайте нет формулировок о доказанной медицинской эффективности VR-проекта. Сгенерированные портреты подписаны как AI; это иллюстрации, а не фото с мероприятий.

## Локальный просмотр

В папке проекта выполнить:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8000/ . Остановить сервер: Ctrl+C.

## Публикация изменений

```sh
git add index.html styles.css carousel.js achievements.json assets README.md
git commit -m "Update personal site"
git push origin main
```

GitHub Pages автоматически опубликует изменения. Статус: https://github.com/ROCK478/ROCK478.github.io/actions
