# Личный сайт Виктора Попова

Сайт: https://rock478.github.io/

Статический сайт без внешних зависимостей и этапа сборки. GitHub Pages публикует корень ветки `main`.

## Содержание и оформление

Визитка универсального IT-специалиста: контакты в начале, направления работы и стек, подход к новой технологии, результаты после побед и одна карусель документов о победах.

Визуальный ориентир по прямому указанию Виктора — лендинг проекта из папки «СтудСтартап / Витязь Продукт»: Manrope, белый фон, тёмно-синий `#12233d`, красный `#d84336`, мягкие скругления и фирменный медведь. Сайт продукта оставлен без изменений. Медведь — символ компании; портретов Виктора на странице и в метаданных нет. Прежние изображения убраны из опубликованных файлов, локальные копии сохранены для возможной будущей работы.

В ленте девять документов о победах. По указанию Виктора подписи «Победитель», «1 место» и «Диплом I степени» приведены к «1 место»; содержание самих документов сохранено. Призовые места, сертификаты участия и обучения убраны из ленты. Полный архив в `ROCK478/MyAchievements` не изменён.

Сведения о роли генерального директора ООО «Витязь», призе 250 000 рублей «Открой#Моспром», продолжающемся сотрудничестве с ООО «АйВиСистемз», двух победах в «Альфа-Будущем» и учёбе на отлично предоставлены Виктором. Текст про первые пять минут описывает подход к освоению технологии: понять задачу, проверить прототипом, собрать продукт.

## Файлы

- `index.html` — содержание и статическая разметка девяти слайдов.
- `styles.css` — оформление и адаптация для телефона; шрифты подключены локально.
- `carousel.js` — листание колёсиком, свайпом, стрелками и клавиатурой; увеличение документов внутри страницы.
- `achievements.json` — данные девяти выбранных побед в порядке показа.
- `assets/documents/` — документы; в карусели используются только выбранные победы.
- `assets/brand/` — фирменный медведь «Витязя».
- `assets/fonts/` — Manrope и лицензия SIL Open Font License.

Карусель не переключается автоматически. На краях продолжается обычная прокрутка страницы. В режиме увеличения доступны масштаб и закрытие по Escape. Поддерживается настройка уменьшения анимации.

## Локальный просмотр

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8000/ . Остановить сервер: Ctrl+C.
